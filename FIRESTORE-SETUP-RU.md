# Настройка синхронизации Let's cook!

В этой версии добавлена синхронизация пользовательских данных через Firebase Firestore. Она заработает только после включения Firestore в проекте Firebase и публикации правил доступа.

## Включить Firestore
1. Открой https://console.firebase.google.com/ и выбери проект `lets-cook-9119c`.
2. Открой **Firestore Database** → **Create database**.
3. Создай базу в подходящем регионе. Для тестирования можно начать с production mode; не выбирай публичные правила.
4. Открой вкладку **Rules** и замени содержимое правилами из файла `firestore.rules`, затем нажми **Publish**.
5. В Authentication → Settings → Authorized domains проверь домен своего Vercel-сайта.

## Проверка
1. Разверни эту версию на тестовом деплое Vercel.
2. Войди тестовым аккаунтом A, добавь рецепт в избранное и товар в список покупок. Подожди несколько секунд при наличии интернета.
3. Войди аккаунтом A на телефоне и проверь данные.
4. Войди аккаунтом B: данные A не должны отображаться.
5. Проверь Firestore → Data: пользовательские документы находятся в `users/{UID}/appData/{key}`.

Гостевой режим остаётся локальным и отдельным; гостевые данные не загружаются в облако и не переносятся между устройствами.

## Важно
- Не публикуй Firestore с открытыми правилами `allow read, write: if true`.
- Старые данные, которые были только в браузере, загружаются в облако при первом входе, если облачная коллекция аккаунта ещё пуста. Перед тестом сделай резервную копию важных данных.
- При ошибке конфигурации данные могут оставаться локальными; проверь Console и Firebase Rules.

## Удаление аккаунта
Кнопка «Удалить аккаунт» в профиле просит пароль, удаляет все документы `users/{UID}/appData/*`, затем сам аккаунт и локальные данные. Это нужно для требований Google Play.
