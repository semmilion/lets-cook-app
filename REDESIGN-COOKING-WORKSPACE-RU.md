# Обновление экрана готовки

- Экран приготовления переработан по референсу: кремовая палитра, оранжевые акценты, карточки с мягкими тенями.
- Добавлены левая панель этапов и ингредиентов, центральная сцена, правая колонка советов и кухонных инструментов.
- Изображение блюда загружается из локальных фотографий проекта; инструменты используют локальные PNG-иллюстрации.
- Адаптивная раскладка для небольших экранов и уменьшения анимации через prefers-reduced-motion.
- Service worker cache обновлён до v17, чтобы браузер запросил новую версию интерфейса.
