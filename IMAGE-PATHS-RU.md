# Исправление изображений — v24

- Все динамические пути к фото еды, сценам готовки и PNG-иллюстрациям теперь начинаются от корня сайта (`/assets/...`), а не от текущего URL.
- Карточки при ошибке сначала пробуют обычное фото рецепта, затем локальный `fallback.svg`, и только после этого показывают эмодзи.
- В режиме готовки сначала выбирается изображение конкретного шага, затем фото блюда, сцена шеф-повара и SVG-запасной вариант. Пустой `alt` предотвращает появление текста «Фото блюда» в блоке изображения.
- Инструменты справа используют отдельные PNG из `assets/illustrations/` с emoji-fallback.

## Важно при публикации
Загружайте в GitHub весь проект целиком, включая папки `assets/food/`, `assets/illustrations/`, `assets/cooking-scenes/`. Если папка `assets/` отсутствует в GitHub, HTML не может получить изображения. После деплоя проверяйте, что URL вида `/assets/food/pancakes.jpg` открывается напрямую.
